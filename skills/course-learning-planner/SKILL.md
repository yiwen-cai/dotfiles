# course-learning-planner

## 规划与辅导
先读该课程当前进度、课程项目约定、作业要求和用户可用时间。根据实际学习目标选择讲义或作业优先，不把另一门课程的顺序套用进来。
计划要对应下一步可完成的学习目标，解释必要背景，再结合习题/实现反馈。仅需解释概念时直接讲解，不强制创建计划文件或测验。
课程有 TA 边界时，解释、提示、审阅和辅助测试优先；不替用户完成禁止代写的作业。远程执行约定以该课程项目为准。

## 输出与测验
沿用项目既有 Markdown/HTML 笔记形式；只有任务要求同步已有多种产物时才同步，不强制为所有课程建三套副本。
用户选择出题或测试理解时读 [optional-quiz.md](references/optional-quiz.md)。测验不构成开发提交门禁。

## 验证
下一步与当前课程内容、时间和执行环境对应；未确定的进度不写成已完成。课程专属规则由课程项目 AGENTS 路由提供。
